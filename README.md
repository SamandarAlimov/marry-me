# Marry Me

An interactive cinematic proposal experience built as a long-term React + TypeScript project.

## Principle

This is not a static romantic landing page. The environment, narrative, motion and interaction are part of the experience itself.

## Stack

- React
- TypeScript
- Vite
- Framer Motion

## Architecture

`engine/` contains reusable scene, narrative, interaction, motion, world and particle primitives. `components/` contains visual systems. `content/` contains narrative copy separately from presentation.

The first product is intentionally focused on **Marry Me**. Date planning, married-life experiences and other concepts will be developed as separate products/repositories later.
